# Hi, I'm Haomin Qi

I work at the intersection of machine learning, information retrieval, NLP, and applied data systems. My recent work spans retrieval-augmented generation, recommendation systems, transformer models, signal recovery, and practical web/data products.

## Current Focus

- Building reliable AI and data systems with clear evaluation loops.
- Applying NLP and retrieval methods to real-world search and reasoning workflows.
- Turning coursework and research prototypes into reproducible public projects.
- Keeping implementation quality readable: structured repos, runnable baselines, and honest experiment notes.

## Selected Work

- `IoT-RAG-ABA`: RAG-oriented work around IoT and applied AI workflows.
- `AWSG-FITE-Web`: CUHK AWSG Lab website and frontend engineering work.
- `ucsd-course-materials`: curated UCSD graduate coursework archive, including NLP, recommender systems, sparse recovery, and image processing projects.

## Technical Areas

**Machine Learning / AI:** NLP, RAG, recommender systems, transformers, ranking, evaluation, experiment design  
**Data / Modeling:** Python, PyTorch, scikit-learn, pandas, feature engineering, time-aware validation  
**Systems / Product:** JavaScript, TypeScript, React, web tooling, reproducible project structure  
**Signal / Image Processing:** sparse recovery, OMP, image restoration, audio reconstruction

## How I Build

- Start with a clear baseline.
- Make experiments reproducible before making them complex.
- Write down assumptions, data splits, and evaluation metrics.
- Prefer small, inspectable systems over opaque demos.

## Open Source Direction

I am gradually publishing cleaned versions of coursework and project archives so future students can learn from concrete implementations, reports, and experiment organization without relying on private course materials.

> Use my coursework repositories as references for learning and project structure, not as submission sources.
